# Bloodecky

Decky Loader plugin to configure and manage Bloodborne via shadPS4 on the Steam Deck based on DeckyBorne.

## Features

[] **Game Files Verification:** Detects base `.pkg` and v1.09 update files.
[] **Profile Selector:** Pre-configured performance and visual profiles (Vanilla, DeckBorne 30/60 FPS).
[] **Mod Manager:** Integrated checklist for essential community fixes and patches.
[] **One-Click Installer:** Automated setup and Steam library tile creation.
